# Vehicle Loan Analysis

Identify the factors that affect the ratio of vehicle-loan defaulters

## 📌 Project Overview

An end-to-end data analytics project focused on understanding loan performance, customer demographics, and credit risk. 
The project combines Python-based data cleaning and validation with an interactive Power BI dashboard to explore loan disbursements, customer characteristics, and default patterns.

## 🎯 Objectives

- Improve data quality through cleaning, validation, and duplicate checks.
- Analyse loan performance and customer distribution.
- Present key business metrics through interactive visualisations.

## 🛠️ Tools & Technologies
- **Python:** Pandas, Logging
- **Data Processing:** Excel, data cleaning, validation, and transformation
- **Business Intelligence:** Microsoft Power BI
- **Analytics:** Exploratory Data Analysis (EDA), KPI analysis, and data visualisation

## 📊 Dashboard Highlights
- **Key Metrics:** Customer count, disbursed loan amount, average LTV, and overall default rate.
- **Loan Performance:** Compliant versus defaulting accounts and disbursement comparisons.
- **Customer Demographics:** Default patterns by age group and employment type.
- **Credit Risk Analysis:** Customer distribution across credit score categories.
- **Trend Analysis:** Monthly loan volumes and default rates.
- **Branch Analysis:** Comparison of customer counts and loan disbursements across branches.

## 💡 Key Learning Outcomes

- Applying Python to data cleaning and validation.
- Translating business questions into meaningful KPIs and visualisations.
- Using Power BI to communicate loan performance and customer risk insights.

## Important notes

- Used synthetic data for this project.
